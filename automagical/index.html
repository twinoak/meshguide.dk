Automagisk opsætning

1. Forbind repeateren

Sæt repeateren i computeren med et USB-kabel og klik Tilslut. Browseren spørger hvilken port den skal bruge. Virker i Chrome og Edge på computer (Web Serial) — ikke i Firefox, Safari eller på telefon. Eksperimentel funktion: siden læser repeaterens indstillinger via dens CLI og skriver kun de ændringer du vælger.

Din browser understøtter ikke Web Serial. Brug Chrome eller Edge på en computer.
